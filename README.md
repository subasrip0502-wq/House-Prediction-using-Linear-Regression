# 🏠 House Prediction Using Regression

## 📌 Project Overview
This project focuses on predicting house prices using **Multiple Linear Regression** in Python. A sample dataset is created using NumPy and Pandas, and a machine learning model is trained to predict house prices based on different property features.

## 🎯 Objective
To build a regression model that predicts house prices using:
- Area (square feet)
- Number of Bedrooms
- House Age
- Kitchen
- Bathroom

## 🛠️ Technologies Used
- Python
- NumPy
- Pandas
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook / Google Colab

## 📊 Project Workflow
1. Generate a sample house dataset.
2. Create features such as area, bedrooms, age, kitchen, and bathroom.
3. Prepare input features (X) and target variable (Y).
4. Split the dataset into training and testing data.
5. Train a Linear Regression model.
6. Predict house prices.
7. Evaluate model performance using regression metrics.
8. Visualize actual and predicted prices.

## 🤖 Machine Learning Algorithm
**Multiple Linear Regression**

The model uses multiple house features to estimate the predicted house price.

## 📈 Model Evaluation Metrics
- Mean Absolute Error (MAE)
- Mean Squared Error (MSE)
- Root Mean Squared Error (RMSE)
- R² Score
